# 0006 — Content Security Policy

Data: 2026-11-13 · Stato: accettata

## Contesto
Privacy per costruzione (sezione 2): i dati della fotocamera non devono poter uscire, e l'app deve
resistere a iniezioni da input, URL o dati importati.

## Decisione
- `security.csp` di Astro genera per ogni pagina un meta CSP con gli hash degli script inline:
  `default-src 'self'`, `connect-src 'self'` più il solo server di sync, `script-src 'self'
  'wasm-unsafe-eval'` (per il WASM di MediaPipe), `style-src-attr 'unsafe-inline'` (stili dinamici
  di Svelte), `object-src 'none'`, `base-uri 'self'`, `form-action 'none'`.
- Nessun `{@html}`, `innerHTML` o `set:html` nel codice, tranne il link al manifest generato in
  build (controllato da un test). Le esportazioni `.ics` e CSV fanno l'escape del contenuto
  (CSV: niente formule eseguibili).
